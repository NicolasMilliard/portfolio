# 404 title font

`Jost-404.ttf` is a locally served, 600-weight Jost subset containing only `0`
and `4`, downloaded from the Google Fonts CSS API. It is used only by the
LOST-inspired 404 title; the portfolio typography is unchanged.

- Typeface:
  [Jost by indestructible type](https://indestructibletype.com/Jost.html)
- Source:
  [Google Fonts Jost](https://github.com/google/fonts/tree/main/ofl/jost)
- License: `Jost-OFL.txt`, distributed beside the font.
